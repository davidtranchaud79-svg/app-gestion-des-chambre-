Gestion des chambres

Ce dépôt contient le code source de la micro-application de réservation.

La vraie application publique ne tourne pas avec GitHub Pages : elle doit être déployée comme application web Google Apps Script, car elle utilise google.script.run et le Google Sheet comme back-office.

Les fichiers utiles sont dans src/Code.gs et src/Index.html.

Après déploiement Apps Script, colle ici le lien public si tu veux remplacer cette page par un bouton d’accès direct.
